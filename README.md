# מחולל הזמנות — המחלקה לעיצוב טקסטיל, שנקר

כלי דפדפן שמייצר הזמנות לאירועי המחלקה לפי שפת המיתוג: נרקיס בלוק / פרנקלין גותיק, אדום #FF4141, קווי גריד #FF0000, אפור #F5F5F5, לוגו TEXTILE וחתימת שנקר.

## מה יש בכלי
- **3 תבניות:** יום פתוח · תערוכה / פתיחה · הזמנה להגשה
- **4 פורמטים:** פוסט אינסטגרם 1080×1080 · סטורי 1080×1920 (עם שוליים בטוחים לממשק אינסטגרם) · קאבר לרוחב 1920×1005 · A4 להדפסה (300dpi)
- **רקעים:** תמונה (עם הכהיה), אפור, לבן, אדום
- העלאת תמונה, זום וגרירה למיקום, קרדיט אנכי לתמונה
- 3 סוגי חתימה: TEXTILE + שנקר · חתימה תלת-לשונית · TEXTILE בלבד
- גודל הטקסט מתאים את עצמו אוטומטית כך ששום דבר לא מתנגש ותמיד נשמרים שוליים נדיבים
- ייצוא PNG, PDF, או כל 4 הפורמטים בלחיצה אחת
- הכול רץ בדפדפן — שום קובץ לא עולה לשרת. הטקסטים האחרונים נשמרים בדפדפן של כל משתמש.

## העלאה ל-GitHub Pages (פעם אחת, כ-5 דקות)
1. ב-github.com: **New repository** → שם, למשל `textile-invites`.
2. **Add file → Upload files** → גוררים את **כל התוכן של התיקייה הזו** (index.html, app.js, logos.js, התיקיות fonts ו-vendor) → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, תיקייה `/ (root)` → Save.
4. אחרי דקה-שתיים הכלי זמין בכתובת: `https://kefflee.github.io/textile-invites/`
5. שולחים את הקישור לצוות. עדכון בעתיד = העלאה מחדש של הקובץ ששונה.

## הערה חשובה על הפונטים
נרקיס בלוק ופרנקלין גותיק הם פונטים מסחריים. ב-GitHub Pages ריפו ציבורי הופך את קובצי הפונט להורדה פומבית, וכדאי לוודא שרישיון הפונט של המחלקה/שנקר מאפשר הטמעה באתר (webfont). אם לא:
- אפשר להשאיר את הריפו פרטי (Pages לריפו פרטי דורש חשבון GitHub בתשלום / Education), או
- לעבור לגרסה שבה הפונטים לא נמצאים באתר, וכל משתמש טוען את קובצי הפונט מהמחשב שלו פעם אחת.

## משקל Black לכותרות
המדריך הסגנוני מגדיר כותרות ב-**Narkis Block Black**, אבל בתיקיית הפונטים יש רק Medium / Regular / Thin. אם יש לכם את קובץ ה-Black — שמרו אותו בשם `fonts/NarkisBlock-Black.ttf` והכלי ישתמש בו אוטומטית לכל הכותרות (עד אז הכותרות ב-Medium).

## קבצים
- `index.html` — הממשק
- `app.js` — התבניות והציור (כל תבנית היא פונקציה ב-`LAYOUTS`; טקסטי ברירת מחדל ב-`TEMPLATES`)
- `logos.js` — הלוגואים כווקטור (הומרו מקובצי ה-PDF בתיקיית המיתוג)
- `vendor/jspdf.umd.min.js` — ייצוא PDF
